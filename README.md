# AH Download Manager

**AH Download Manager v1.0.0 — Windows 64-bit**

A Windows desktop download manager with a premium installation experience.

## Features

- Download management
- Multiple downloads
- Smart scheduling
- Windows desktop application
- Premium Blue & Gold Setup Wizard
- Installation, update and uninstall options

## System Requirements

- Windows 10 / 11 (64-bit)
- Internet connection for online downloads

## Download

Get the latest Windows installer from the official GitHub Releases page:

[Download AH Download Manager](https://github.com/Heraphull/AH-DM-Releases/releases)

## Installation

1. Download `AHDM.Setup.exe` from GitHub Releases.
2. Run the installer.
3. Follow the installation wizard.
4. Launch AH Download Manager after installation.
